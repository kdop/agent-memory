Database Schema (v1.0)
══════════════════════

memories
  ├── id (PK)
  ├── timestamp (indexed)
  ├── agent (indexed)
  ├── project (indexed)
  ├── content (FTS5-indexed)
  └── type (indexed)

tags
  ├── id (PK)
  └── name (unique, case-insensitive)

memory_tags
  ├── memory_id → memories.id (indexed)
  └── tag_id → tags.id (indexed)

memories_fts (FTS5 virtual table)
  └── content (full-text search)

════════════════════════

memory projects

Features
════════

✅ Auto-timestamping (local timezone)
✅ Project scoping
✅ Multi-agent support
✅ Case-insensitive tags
✅ Full-text search (FTS5)
✅ Date range queries
✅ Combined filters
✅ Fast indexed queries
✅ Scales to 100k+ memories
✅ Auto-migration
✅ WAL mode (better concurrency)


Installation
════════════

1. Tool is at: ~/workspace/agents/memory-cli
2. Add to PATH: export PATH="$HOME/workspace/agents:$PATH"
3. Set agent: export AGENT_NAME=agent-a
4. Test: memory stats


Usage Examples
══════════════

# Add memories
memory add "Fixed auth bug" --project=myapp --tags=bugfix,auth --type=code

# Query
memory query --today
memory query --project=myapp --tag=auth --since=2026-05-01

# Search
memory search "authentication" --project=myapp

# Explore
memory tags
memory projects


Performance
═══════════

10k memories:   ~10 MB, queries <5ms
100k memories:  ~100 MB, queries <50ms
1M memories:    ~1 GB, queries <500ms
